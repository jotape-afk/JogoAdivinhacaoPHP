# Jogo de Adivinhação

Um jogo simples de terminal feito em PHP e C++ onde o jogador precisa descobrir um número aleatório entre 1 e 100.

O jogo fornece dicas de proximidade e direção para ajudar o jogador a encontrar a resposta correta.

## Exemplo

```txt id="z0pjli"
Digite um numero (1 - 100): 50
↓ Muito frio

Digite um numero (1 - 100): 30
↑ Esquentando

Digite um numero (1 - 100): 41
↑ QUEIMANDO

Digite um numero (1 - 100): 44

CERTA RESPOSTA: 44
```

## Como executar
Recomendo executar pelo VSCode (caso já esteja configurado), Dev-C++ no caso do C++, ou utilizar compiladores online como o [Online C Compiler](https://www.onlinegdb.com/online_c_compiler) ou o [OnlinePHP](https://onlinephp.io)
